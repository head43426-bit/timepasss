What formats does it accept?
  • JSON lines: {"time":"...","host":"WS-01","user":"priya","action":"...","detail":"..."}
  • Pipe: time|host|user|source|action|detail|stage|mitre|severity
  • Plain lines are searched for attack words.

5+ failed logins for the same user on the same host become one brute-force detection. A single failed login never flags. Flagged lines link into incidents by host, user, IP and time.
