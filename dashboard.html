Formats it understands

  • JSON lines: {"time":"...","host":"WS-01","user":"priya","action":"...","detail":"..."}
  • Pipe: time|host|user|source|action|detail|stage|mitre|severity
  • Plain lines: the whole line is searched for attack words (host/user left blank if not in the line).

How it decides

Keyword rules tag each suspicious line with a MITRE technique and kill-chain stage. 5+ failed logins for the same user on the same host within 60 minutes become one brute-force detection - a single failed login never flags. Flagged lines are linked into incidents when they share a host, user, or IP within 48 hours. Everything else is counted as benign and dropped.
